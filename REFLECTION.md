# Q: What did you repeat by hand? What broke when you moved a file? What would you want a tool to generate for you?

## What I repeat by hand:

- I repeated copying the head, header, nav, and footer to all the pages so they have the same meta tags, links, logo, nav links, and copyright line.
- I also copied the same page structure for all four cheese family pages, and I found this very repetitive. Their structures are identical, they just have different content (text, image, and prev/next hrefs). I spent most of my time structuring the fist cheese page, then copied, pasted, and edited it a little bit for the other three cheese.
- Since it was so repetitive, sometimes, I forgot to change/ update the content such as the title, the alt text, or the prev and next hrefs.

## What broke when I moved a file:

- I found the paths broke when copying to different file, especially when the file was located inside another folder. It took me a while to manually fixed all the file paths such as all the stylesheets, logo, nav links, and href after copying and pasting from file to file.

## What would I want a tool to generate:

- I think it would be nice to have a tool that copies and pastes the head, header, nav, and footer to all the pages for me since these are identical. Maybe I could define it once, like a function, and call it so that every pages has the same structure.
- Also, I think the 4 cheese family pages should all share one single html file because their page structures are the same. Maybe we can have 4 different and separate data files for each cheese, and we can pull the right data into the html file depending on which cheese the user is viewing. I think this way, it would make maintenance easier. If we want to change the structure for these cheese family, we would only need to change it once instead of four different pages.
